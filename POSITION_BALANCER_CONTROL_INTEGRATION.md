# Position Balancer Control Commands - Complete Integration Guide

## Overview

The position balancer runtime controls have been fully integrated into the Hummingbot framework's `control` command infrastructure. Users can now enable/disable buy-in and sell-off modes using native Hummingbot commands with autocomplete support.

```bash

async def _control_enable_buyin(self, identifier: str):
    try:
        strategy = self.trading_core.strategy
        success = strategy.enable_buyin_by_identifier(identifier)

        if success:
            self.notify(f"\n✓ Buy-in enabled successfully for {identifier}")
        else:

```

### 5. Orchestrator Lookup (multi_strategy_orchestrator.py)
```python
def enable_buyin_by_identifier(self, identifier: str) -> bool:
    # Try exact name match
    strategy_instance = next(
        (s for s in self.strategies if s.name == identifier),
        None
    )

    if strategy_instance:
        return self.enable_buyin(identifier)

    # Try token lookup
    strategy_instance = self._find_strategy_by_token(identifier)
    if strategy_instance:
        return self.enable_buyin(strategy_instance.name)

    return False
```

### 6. Orchestrator Direct Method (multi_strategy_orchestrator.py)
```python
def enable_buyin(self, strategy_name: str) -> bool:
    strategy_instance = next(
        (s for s in self.strategies if s.name == strategy_name),
        None
    )

    if not strategy_instance:
        return False

    # Check if strategy has position balancer
    if not hasattr(strategy_instance, '_position_balancer') or \
       strategy_instance._position_balancer is None:
        return False

    # Enable buy-in
    strategy_instance._position_balancer.enable_buy_in()
    return True
```

### 7. Position Balancer Handler (position_balancer_handler.pyx)
```python
def enable_buy_in(self):
    """Enable buy-in mode and reset completion flag"""
    if not self._buy_enabled:
        self._buy_enabled = True
        self._buy_completed = False
        self.strategy.log_with_clock(
            logging.INFO,
            "Buy-in mode enabled - position balancer will acquire assets to reach target")
```

## Capability Checks

The framework performs multiple validation checks:

### 1. Strategy Running Check
```python
if not self.trading_core.strategy:
    self.notify("No strategy is currently running.")
    return
```

### 2. Control Support Check
```python
has_control = (
    hasattr(strategy, 'enable_buyin_by_identifier') and
    hasattr(strategy, 'disable_buyin_by_identifier') and
    hasattr(strategy, 'enable_selloff_by_identifier') and
    hasattr(strategy, 'disable_selloff_by_identifier')
)

if not has_control:
    self.notify("The current strategy does not support runtime control.")
    return
```

### 3. Position Balancer Check
```python
if not hasattr(strategy_instance, '_position_balancer') or \
   strategy_instance._position_balancer is None:
    self.logger().error(f"Strategy '{strategy_name}' does not have position balancer enabled")
    return False
```

### 4. Strategy Existence Check
```python
strategy_instance = next(
    (s for s in self.strategies if s.name == identifier),
    None
)

if not strategy_instance:
    # Try token lookup fallback
    strategy_instance = self._find_strategy_by_token(identifier)
```

```
✗ Failed to enable buy-in for: INVALID
  Strategy may not have position balancer enabled
  Use 'control list' to see available strategies
```

**No Position Balancer:**
```
✗ Failed to enable buy-in for: arb_bsx
  Strategy may not have position balancer enabled
  Use 'control list' to see available strategies
```

**No Identifier Provided:**
```
Error: Please specify a strategy name or token symbol.
Usage: control enable_buyin <strategy_name_or_token>
```

**No Strategy Running:**
```
No strategy is currently running.
```

**Strategy Doesn't Support Controls:**
```
The current strategy does not support runtime control.
Runtime control is available for multi-strategy orchestrators
like scripts/multi_strategy_orchestrator.py
```
